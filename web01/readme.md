# 청주 문화관광 웹사이트

청주시의 관광명소, 문화유산, 축제, 여행가이드 정보를 제공하는 정적 웹 퍼블리싱 프로젝트입니다.  
PC와 모바일 화면을 고려한 반응형 레이아웃, 공통 헤더/푸터, 다단 메뉴, 관광 콘텐츠 상세 페이지를 중심으로 구현했습니다.

## 주요 기능

### 메인 페이지

- 메인 비주얼 배너
- 대표 관광 콘텐츠 소개
- 관광/축제/문화/여행가이드 메뉴 이동
- 유관기관 배너 링크

### 관광 정보

- 역사문화관광
- 교육체험관광
- 생태자연관광
- 농촌체험관광
- 레저관광
- 관광명소 상세 페이지

### 축제/문화 정보

- 청주 주요 축제 안내
- 국가유산/등록유산/향토유적/문화공간 소개
- 이미지 기반 상세 콘텐츠 구성

### 여행가이드

- 여행사 정보
- 관광지도 신청
- Contact 페이지
- 개인정보 처리방침

### 회원 관련 화면

- 로그인 화면
- 회원가입 화면

## 실행 방법

별도 빌드 과정이 없는 정적 웹사이트입니다.

```text
web01/index.html
```

위 파일을 브라우저에서 열면 웹사이트를 확인할 수 있습니다.  
로컬 서버를 사용할 경우 `web01` 폴더를 문서 루트로 지정하면 됩니다.

---

## 점검 결과

- 현재 `web01`은 백엔드 없이 동작하는 정적 HTML/CSS 프로젝트입니다.
- `readme.md`의 오래된 `css/`, `geojae` 폴더 표기를 실제 구조에 맞게 정리했습니다.
- 존재하지 않는 `sub5.html`, `sub51.html`, `sub52.html` 링크는 `#` 더미 링크로 수정했습니다.
- `package-lock.json`은 있으나 `package.json`이 없어 npm 기반 실행 프로젝트는 아닙니다.

## 회고

HTML5 시맨틱 마크업과 CSS 레이아웃 설계를 연습하며, 관광 정보처럼 콘텐츠 양이 많은 웹사이트를 구조화하는 경험을 쌓았습니다.  
공통 내비게이션, 상세 페이지 레이아웃, 반응형 스타일을 구성하면서 사용자 흐름과 정보 전달 중심의 화면 설계를 학습했습니다.
