# 김승민 포트폴리오

Java/Spring 기반 웹 개발자 포트폴리오입니다. Spring Boot REST API, PostgreSQL 데이터 처리, 인증/인가, 외부 시스템 연동 경험을 중심으로 정리했습니다.

## 주요 기술

- Java
- Spring Boot
- PostgreSQL
- REST API
- Vue.js
- JPA
- Spring Security
- Git/GitHub
- Docker

## 대표 프로젝트

- TAS: 외부 FastAPI 분석 서버 결과를 Spring Boot 백엔드에서 수신하고, 차량 감지 로그/OCR 결과/과속 위반 데이터를 저장·조회하는 교통 데이터 처리 프로젝트입니다. 팀 프로젝트에서 Spring Boot 백엔드 개발을 주력으로 담당했습니다.
- TeamKeto: Vue.js 프론트엔드와 Spring Boot 백엔드로 구성한 쇼핑몰 프로젝트로, 회원·상품·장바구니·주문·리뷰·게시판 API를 구현했습니다.
